# where-is-mom
Wondering where someone on a cruise vacation is right now?  This is a quick mobile app to make answering the question 'where are they now?' easy.

It provides real-time tracking of a family trip on a ship via AIS, supplimented with photo/EXIF tracking for land based trips.  You can see the historical log of places they've been, along with the clickable thumbnails of photos they've taken on land.

Note that you must make sure to upload the photos with EXIF information for proper location tracking - most mobile devices now strip this out on upload, unless you take special steps, e.g, exporting the photo out of the camera/photo app into the filesystem.
